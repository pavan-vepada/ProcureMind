# sample-data · the fictional world the product runs on

Everything here is invented: **Sunrise Consumer Goods**, its two plants, its buyer, and its suppliers.

| File | What it is |
|---|---|
| [`context.json`](context.json) | The company, the plant's request, and the supplier shortlist (hand-written) |
| [`demo.json`](demo.json) | The main sourcing event: 30 items, the quality questionnaire, last year's contracts, every supplier reply, and the **answer key** used to check accuracy |
| [`extra.json`](extra.json) | The other sample events and the waiting request |
| [`files/`](files/) | The actual supplier replies, exactly as a buyer would receive them |

**Open the files in [`files/`](files/) to see the mess the product deals with:** an Excel sheet in a supplier's own layout (`kaveri-quotation.xlsx`), a PDF in US dollars with a footnote discount (`deccan-boxboard-quote.pdf`), a Word document that skips items (`shakti-quote.docx`), a tilted phone photo of a rate card (`narmada-rate-card.jpg`), and an expired certificate (`narmada-iso-9001.pdf`).

`demo.json`, `extra.json` and `files/` are generated by [`tools/dataset`](../tools/dataset/), so the traps and the answer key always match. The generator gives the same output every time.
